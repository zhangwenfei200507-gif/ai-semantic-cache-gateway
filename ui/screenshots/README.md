# Semantic Gateway console screenshots

Captures show the frontend against a loopback fixture server. Workspace history, prompts, provider metadata, costs, and diagnostics are synthetic. Desktop screenshots use a 1440 × 1150 viewport; mobile samples use 390 × 884.
